# The Snake 2

Современная аркадная «Змейка» на единой кодовой базе **TypeScript + Vite + HTML5 Canvas 2D + Web Audio API + Electron**, работающая в двух режимах: **Веб (ПК, телефоны, планшеты)** и **ПК-приложение (Electron)**.

Вся графика, анимации, частицы, звуковые эффекты и адаптивная музыка генерируются **100% кодом** без внешних изображений и аудиофайлов.

## Ключевые особенности

- **Архитектура «Чёрные ящики и контракты»:** строгое разделение на Датчики, Коммутатор (`EventBus`), чистые Обработчики, Хранилища и Исполнителей. Ядро (`src/core/`) не зависит от DOM, Canvas, Audio или Electron.
- **Уровневая прогрессия:** на каждом уровне фиксированное число хороших яблок, плохих яблок и камней с весом. Цель уровня — собрать все хорошие яблоки; чем меньше ходов и ошибок, тем выше бонус эффективности.
- **Змеиное бешенство (`Frenzy`):** при долгом отсутствии хороших яблок змейка начинает «звереть» и плавно ускоряется, меняет окрас, искрит и ускоряет темп процедурной музыки. Хорошее яблоко мгновенно успокаивает змейку.
- **Пополняемые жизни:** потеря жизни перезапускает текущий уровень с сохранением счёта; дополнительные жизни выдаются за набор очков (`+1 жизнь` каждые `1200` очков, до `5`).
- **Три уровня сложности:** `Легко (×1.0)`, `Нормально (×1.5)`, `Сложно (×2.0)` — влияют на множитель очков, скорость, частоту бешенства, количество препятствий и вес камней.
- **Управление для ПК и сенсорных экранов:** `WASD` / стрелки, `Space` / `P` пауза, `M` звук; на телефонах и планшетах — свайпы и адаптивный D-pad.
- **Процедурный звук и настройки громкости:** раздельные регуляторы `Общая`, `Музыка`, `Эффекты` и быстрый `Mute`.

## Команды запуска

```bash
# Установка зависимостей
npm install

# Веб-режим (разработка)
npm run dev

# Продакшн-сборка веб-версии (dist/)
npm run build

# ПК-режим (Electron поверх собранной игры)
npm run desktop

# ПК-режим в разработке (Vite + Electron)
npm run desktop:dev

# Проверка типов и тесты ядра
npm run typecheck
npm run test
```
